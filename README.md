## Usage

- Slash: `/fdt` (alias `/mdt`)
- Mob tracker: `/fdt track on|off|apply|reset|status|name <mob name>`
- Map diagnostics: `/fdt where`
- SavedVariables: `FDTDB`
- Interface: 16001, 11509
